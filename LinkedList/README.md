Linked List is primitive data structure that stores data at any position in memory. It is dynamic memory data structure.

## Time Complexity
 - Prepend = O(1)
 - append = O(1)
 - lookup = O(n)
 - insert = O(n)
 - delete = O(n)

## Linked List Types
 - Singly Linked List: pointer to the next item only.
 - Doubly Linked List: pointer to previous and next item.
 - Circular Linked List: the last node points back to the head node.

## Implemented Operations
 - Singly Linked List: append, prepend, insert, remove, display, reverse.
 - Doubly Linked List: append, prepend, insert, remove, display.
 - Circular Linked List: append, prepend, insert, remove, lookup, display.

## Files
 - Singly Linked List: `SinglyLinkedList/operations.py`
 - Doubly Linked List: `DoublyLinkedList/operations.py`
 - Circular Linked List: `CircularLinkedList/operations.py`
