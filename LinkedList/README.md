Linked List is primitive data structure that store data at any position in memory. It is dynamic memory data structure.

## Time Complexity
 - Prepend = O(1)
 - append = O(1)
 - lookup = O(n)
 - insert = O(n)
 - delete = O(n)

## Singly Linked List and Doubly Linked List
 - Singly Linked List: pointer to the next item only.
 - Doubly Linked List: pointer to previous and next item.
